# 코스콤 코쇠 본문 삽화

## 핵심 정의

한국어 문서의 핵심 판단·흐름·구조·상태·은유 하나를 골라 16:9 가로 손그림 삽화로 만든다. 상업 일러스트, PPT 인포그래픽, 귀여운 마스코트 포스터가 아니다. **흰 종이에 쓱 그린, 조금 엉뚱하지만 1초 만에 이해되는 설명 스케치**가 목표다.

고정 캐릭터는 **코쇠**(코스콤 + 꺾쇠 `>` + 단단한 쇠)다. 진회색 키캡 모양 몸통, 머리 위 오렌지 꺾쇠, 흰 점 눈, 가는 팔다리. 자본시장 인프라를 묵묵히 굴리는 무표정한 운영자다. 코쇠는 장식이 아니라 **그림의 핵심 동작을 직접 수행**해야 한다.

## 워크플로

### 1. 본문 소화

사용자가 준 글·링크·문서·스크린샷을 읽고 정리한다.

- 핵심 주장은 무엇인가
- 인식의 전환이 일어나는 단락은 어디인가
- 그림이 설명을 도와줄 곳, 글만으로 충분한 곳은 어디인가

모든 단락에 고르게 넣지 않는다. "인식 앵커"를 우선한다: 핵심 판단, 병목, 입력→처리→출력, 분기, 전후 비교, 하나로 여러 쓰임, 연결 경로, 흔한 함정, 상태 변화.

### 2. 삽화 기획 (shot list)

"어디에 그림 넣을지 봐줘" 같은 요청이면 생성 전에 shot list만 낸다. 각 컷마다:

- 들어갈 위치 (어느 단락 뒤)
- 주제 / 핵심 의미
- 구조 유형
- 코쇠가 하는 일
- 주요 사물 1~2개
- 한국어 라벨 3~5개 (각 2~8자)

기본 4~8컷. 짧은 글은 1~3컷, 긴 글도 9컷을 넘기지 않는다.

### 3. 한 장씩 생성

사용자가 "만들어줘/생성해줘/그려줘"라고 명확히 요청하면 확인을 기다리지 말고 생성한다. **한 번에 한 장**, 여러 컷을 한 이미지에 합치지 않는다.

`references/prompt-template.md`의 템플릿을 채워 프롬프트를 만들고, 반드시 `assets/kosoe-character-sheet.png`를 레퍼런스로 붙인다.

- **Codex에서 실행 중일 때**: 기준 이미지를 먼저 열어 본 뒤 내장 `image_gen` 도구로 생성한다.
- **Claude Code 등 이미지 생성 도구가 없는 에이전트**: Codex CLI(ChatGPT 로그인)를 호출하는 스크립트를 쓴다. Windows에서는 Git Bash로 실행한다.

  ```bash
  bash <이 스킬 경로>/scripts/gen_image.sh prompt.txt out/01-topic.png <이 스킬 경로>/assets/kosoe-character-sheet.png
  ```

  한 장에 1~3분 걸린다. 여러 장이면 2~4개씩 병렬로 돌린다(각 호출 사이 10~20초 간격). `codex login status`가 ChatGPT 로그인이 아니면 사용자에게 `codex login`을 부탁한다.

이전 예시 구도를 재사용하지 않는다. 매번 현재 글에서 새로운, 조금 이상하지만 말이 되는 물리적 은유를 발명한다.

### 4. 검수와 반복

생성 후 이미지를 직접 열어 `references/qa-checklist.md`로 확인한다. 다음이면 재생성하거나 편집한다.

- 코쇠가 장식으로만 서 있다 / 코쇠 디자인이 기준 이미지와 다르다(검은색 몸, 꺾쇠 없음, 꺾쇠 방향 반대 등)
- 화면이 꽉 찼다, PPT·순서도처럼 보인다
- 한글 오탈자, 라벨 과다, 왼쪽 위 제목
- 지나치게 귀엽거나 유치하다, 배경이 순백이 아니다
- 코스콤 로고(워드마크)를 그려 넣었다

### 5. 저장과 전달

작업 공간에 다음 경로로 저장한다. 기존 파일은 사용자가 명시하지 않는 한 덮어쓰지 않는다.

```text
assets/<article-slug>-illustrations/01-topic-name.png
assets/<article-slug>-illustrations/02-topic-name.png
```

생성에 쓴 프롬프트도 같은 폴더 `prompts/`에 남겨 두면 재생성이 쉽다.

## PPT 덱에 넣을 때

사용자가 .pptx를 주며 "그림 넣어줘 / 장표마다 보완해줘 / 애니메이션"을 요청하면 `references/pptx-workflow.md`를 따른다.
요약: `scripts/pptx/render.ps1`·`inspect_deck.py`로 덱과 빈 자리 파악 → 메인(대기 자리)·스팟(제목 오른쪽 띠) 기획 →
병렬 생성 → `insert_images.py`로 삽입 → 렌더 검수 → 애니메이션(① 등장 / ③ `layers.py`·`place_layers.py`·`animate.ps1`) →
`export_video.ps1`로 프레임 검수 → 필요하면 `theme_fonts.py`로 한글(ea) 폰트 정리. 원본은 덮어쓰지 않고 새 이름으로 저장한다.
렌더링·애니메이션 도구는 Windows + PowerPoint에서만 동작한다.

## 전달 형식

생성 전 기획은 짧고 정확하게. 생성 후에는 다음만 알려준다.

- 몇 장을 만들었는지
- 각 그림의 용도와 들어갈 위치
- 저장 경로
- 가장 안정적인 컷과 선택적인 컷

화풍 이론을 길게 설명하지 않는다. 그림이 말하게 한다.

## 브랜드 주의

- 코스콤 로고(워드마크·아이콘)는 CI 규정상 변형이 금지되므로 **그림 안에 로고를 그리지 않는다**. 코쇠의 오렌지 꺾쇠는 CI 색과 모티프만 차용한 캐릭터 요소다.
- 대외 배포물은 사내 홍보·브랜드 담당 부서의 검토를 거치도록 안내한다.
