# 구도 패턴과 독창성 규칙

## 기본 구조 유형

하나만 고른다. 여러 개 섞지 않는다.

### 워크플로
입력 → 처리 → 출력. 업무 자동화, 데이터 파이프라인, AI 활용 흐름.
왼쪽 입력, 가운데 코쇠나 이상한 기계가 처리, 오른쪽 출력. 오렌지 화살표가 주 흐름.

### 시스템 부분도
데이터 소스, 필터, 저장소, 게이트웨이, 관제 등 시스템의 한 조각.
핵심 모듈 3~5개만. 코쇠가 그중 결정적인 동작 하나를 맡는다.

### 전후 비교
혼란/정돈, 수작업/자동화, 분산/통합, 불안/안정.
왼쪽 혼란, 오른쪽 안정, 가운데 오렌지 화살표. 캐릭터는 과장해도 된다.

### 상태 변화
사용자의 고충, 담당자의 상태, 시스템이 막혔다가 돌아가는 과정.
작은 상태 2~4개, 각 상태에 짧은 라벨 하나.

### 개념 은유
거대한 이상한 기계·창고·금고 하나와 적은 입력, 하나의 출력. 기억에 남아야 한다.

### 계층
방법론, 시스템 계층, 역량 스택. 정식 피라미드 금지. 상자가 층층이 쌓여 있고 코쇠가 벽돌을 나르거나 쌓는다.

### 지도·경로
아이디어에서 오픈까지, 고객 여정, 전환 로드맵. 구불구불한 길 하나, 노드 몇 개, 코쇠가 줄을 끌거나 걷는다.

### 짧은 만화 컷
실패에서 성공, 실제 과정, 도입 전후. 2~4컷, 컷마다 동작 하나.

## 은유 발명법

매번 현재 글에서 새로 발명한다. 예전 그림을 재사용하지 않는다.

1. 추상 개념을 **물리적 동작**으로: 막힌다, 샌다, 무거워진다, 거른다, 쌓인다, 줄을 선다, 동시에 나눈다, 잠근다, 옮겨 심는다, 접는다, 풀린다, 되돌아온다.
2. 시스템 구조를 **로우테크 사물**로: 낡은 기계, 금고, 서랍, 깔때기, 저울, 우편함, 문, 우물, 사다리, 수도관, 실타래, 수문, 회전문, 톨게이트, 도장, 초시계, 분수대, 열기구, 콘센트.
3. **코쇠가 그 동작을 수행**: 옆에 서 있지 않고, 기계 안에서 레버를 당기고, 줄을 감고, 문을 지키고, 나르고, 고치고, 재고, 도장을 찍는다.

사물은 1~2개만 고른다. 쌓아 올리지 않는다.

## 반복 금지 규칙

`assets/examples/`는 선 밀도, 여백, 색 절제, 코쇠의 참여 방식만 보정하는 용도다. 사용자가 "이 그림처럼 / 이 구도로"라고 명시하지 않으면 아래 기존 구도를 재사용하지 않는다.

- 코쇠가 핸들을 돌리는 시세 분수대와 컵 다섯 개
- 열기구에 매달린 원장 금고 위에서 장부 쓰는 코쇠
- 서랍 세 개에서 실을 뽑아 실타래로 감는 코쇠
- 톨게이트 감시 의자에서 도장 찍는 코쇠와 뿔 달린 봉투
- 커피 그라인더에 보고서를 넣는 코쇠와 돋보기 코쇠
- 9시 주문 파도와 회전문
- 사다리 위에서 표준 콘센트를 뚫는 코쇠

같은 주제라도 은유를 바꾼다. 예: "시세 동시 배포"를 분수대 대신 코쇠가 줄 하나로 여러 종을 한꺼번에 울리는 장면으로.
