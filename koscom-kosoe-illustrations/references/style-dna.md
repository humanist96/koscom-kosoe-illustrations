# 화풍 DNA

## 한 줄 요약

순백, 미니멀, 손그림, 여백, 절제, 엉뚱함, 제품 스케치 감성, 한글 손글씨. 구조는 분명하지만 설명서는 아니다.

자본시장 IT를 오래 다뤄 온 엔지니어가 회의실 화이트보드 옆 흰 종이에 쓱 그린 설명 스케치 같은 느낌.

## 반드시

- 16:9 가로 본문 삽화.
- 순백 배경: 베이지·웜그레이·종이 질감·그라데이션·그림자·노이즈 금지.
- 진한 차콜 손그림 선: 가늘고 살짝 떨리는 선. 기계적인 벡터, 두꺼운 외곽선 금지.
- 사물은 선만 (안쪽 흰색). 회색 음영으로 사물을 칠하지 않는다. 회색 면은 코쇠 몸통에만 쓴다.
- 넉넉한 여백: 주제가 화면의 40~60%, 최소 35%는 빈 공간. 조용한 빈 영역이 한 덩어리 있으면 좋다.
- 한글 손글씨 라벨: 최대 5개 (많아도 8개), 각 2~8자.
- 한 장에 핵심 동작·구조·상태·은유 하나.
- 구조 유형 이름을 그림에 쓰지 않는다.

## 색 — 코스콤 CI에서 가져온 팔레트

코스콤 CI는 "오렌지와 진한 회색의 강한 대비로 기술과 고객의 조화"를 표현한다. 이 대비를 삽화의 뼈대로 쓴다.

| 역할 | 색 | 용도 |
| --- | --- | --- |
| 선 | 차콜 `#333333` 근처 | 모든 선, 사물, 기본 글자 |
| 코쇠 몸통 | CI 진회색 `#5A5555` | 코쇠 몸통 채움에만 사용 |
| 메인 흐름 | CI 오렌지 `#E96717` | 코쇠의 꺾쇠, 주 흐름·경로·화살표, 핵심 결과 라벨 1개 |
| 보조 | 블루 `#4368F2` | 보조 설명, 시스템 상태, AI/자동화 메모, 통과·정상 |
| 경고 | 레드 `#E53935` | 문제·위험·경고 하나만. 없으면 안 써도 된다 |

- 오렌지가 주인공 색이다. 다른 색은 아낀다. 블루와 레드는 매번 쓸 필요 없다.
- **증시 관례 주의**: 한국 증시에서 빨강=상승, 파랑=하락이다. 시세·주가를 다루는 그림에서는 빨강/파랑을 방향 의미로 오해하지 않게 쓰거나, 의도적으로 그 관례를 따른다고 프롬프트에 명시한다.

## 절대 금지

- 상업 일러스트, 반짝이는 플랫 벡터
- PPT 인포그래픽, 정식 순서도, 시스템 아키텍처 다이어그램, 교육용 슬라이드
- 귀여운 마스코트 포스터, 아동 일러스트, 이모티콘 느낌
- 실제 UI 스크린샷, HTS 화면, 차트 대시보드 재현, 네온 테크 느낌
- 복잡한 배경, 그라데이션, 그림자, 텍스처
- 모든 노드에 설명 달기
- 왼쪽 위에 "프로세스 / 아키텍처 / 로드맵 / 흔한 실수" 같은 제목
- **코스콤 로고(워드마크·아이콘) 그려 넣기** — CI 규정상 변형 금지

## 미감 방향

엉뚱하고, 창의적이고, 재미있고, 담백하고, 깔끔하게.

귀엽거나, 유치하거나, 복잡하거나, 딱딱하지 않게. 금융회사다운 **신뢰감**은 정돈된 여백과 절제된 색에서 나온다.
